# DataMatch 2026: Аналитический трек
## Методика комплексной оценки полевых игроков для ХК «Авангард»

Репозиторий содержит решение аналитического трека хакатона **DataMatch 2026**. Разработана объективная трехкомпонентная методика оценки изолированного вклада полевых игроков (нападающих и защитников), предназначенная для трансферных, контрактных и тактических решений клуба.

### Содержание репозитория

| Файл / Каталог | Описание |
| :--- | :--- |
| **`test_ratings.csv`** | Итоговые оценки 636 игроков сезона 2025/26 с 90% доверительными интервалами |
| **`reproduce_ratings.ipynb`** | Воспроизводимый Jupyter Notebook: полный пайплайн от сырых данных до оценок и анализа «Авангарда» |
| **`МЕТОДИКА.md`** | Полный отчет: бизнес-проблема, аудит данных, математические формулы, валидация и кейсы селекции |
| **`presentation.pdf`** | 10-слайдовая презентация PDF: методика простыми словами, проверка устойчивости, границы применимости |
| **`run_pipeline.py`** | Консольный скрипт пакетного запуска сквозного пайплайна | 
| **`src/`** | Модульная кодовая база алгоритмов (TOI, xG, xT, RAPM, Evaluate) |

### Архитектура методики

Методика устраняет ключевые пороки традиционной статистики (очков и полезности $+/-$): иллюзию результативности из-за удачи на бросках партнеров и вратаря, смешение вклада партнеров по звену и влияние неравенства составов.

### Результаты эмпирической валидации

Валидация устойчивости (Split-Half Reliability) проведена на $N = 718$ квалифицированных игроках ($\ge 4$ матчей) путем сравнения показателей в четных и нечетных матчах:

| Метрика игрока | Корреляция Пирсона ($r$) | Ранговая Спирмена ($\rho$) | Дисперсия ($R^2$) | Вывод для скаутинга |
| :--- | :---: | :---: | :---: | :--- |
| **Традиционный $+/-$ за 60 мин** | **0.0452** | 0.0612 | **0.2%** | **Чистый случайный шум** (99.8% удачи) |
| **Очки за 60 минут ($P/60$)** | **0.1992** | 0.1875 | **4.0%** | Крайне неустойчиво на коротких выборках |
| **Ожидаемые голы команды ($xG$ Net / 60)** | **0.1757** | 0.1709 | **3.1%** | Умеренная устойчивость качества моментов |
| **Ценность действий (Action Value / xT)** | **0.4571** | **0.4310** | **20.9%** | **В >100 раз стабильнее $+/-$ по $R^2$** |

**Научная база:** Результаты подтверждают фундаментальные выводы школы спортивной статистики НХЛ (*Nandakumar & Jensen, Wharton, 2019*; *Macdonald, 2012*; *Tulsky, 2011/2013*): традиционный плюс-минус непригоден для селекции на малых выборках, в то время как микро-действия и регуляризованный RAPM обеспечивают устойчивый аналитический сигнал.

### Воспроизведение результатов (Quickstart)

#### 1. Требования к окружению
- Python 3.10+
- Библиотеки: `pandas`, `numpy`, `scipy`, `lightgbm`, `scikit-learn`, `matplotlib`, `pyarrow`

```bash
pip install pandas numpy scipy lightgbm scikit-learn matplotlib pyarrow
```

#### 2. Запуск через Jupyter Notebook (для жюри)
Открыть и выполнить все ячейки:
```bash
jupyter notebook reproduce_ratings.ipynb
```
Ноутбук последовательно выполняет все фазы, проверяет промежуточные метрики, строит распределения, генерирует `test_ratings.csv` и выводит детальный анализ игроков ХК «Авангард».

#### 3. Запуск через консольный скрипт
```bash
python run_pipeline.py
```
Время полного цикла исполнения: **~120 секунд**.

### Структура файла `test_ratings.csv`

| Колонка | Тип | Описание |
| :--- | :--- | :--- |
| `player_id` | string | Идентификатор игрока |
| `rating` | float | Итоговый изолированный рейтинг (вклад в разницу ожидаемых голов за 60 минут) |
| `ci_lower` | float | Нижняя граница 90% доверительного интервала (блочный бутстрэп) |
| `ci_upper` | float | Верхняя граница 90% доверительного интервала (блочный бутстрэп) |
| `position` | string | Амплуа игрока (`C`, `LW`, `RW`, `D`, `G`) |
| `team_id` | string | Клуб игрока в тестовом сезоне 2025/26 |
| `matches_played` | int | Количество сыгранных матчей в выборке |
| `toi_total_min` | float | Суммарное время на льду (минуты) |
| `rating_off` | float | Атакующий компонент рейтинга (генерация $xG$ команды за 60 мин) |
| `rating_def` | float | Оборонительный компонент рейтинга (подавление $xG$ соперника за 60 мин) |

*Примечание:* Для вратарей выставлен нейтральный базовый уровень $0.00$ с симметричным интервалом $[-0.15, +0.15]$, так как модель оценивает полезность полевых игроков.

### Границы применимости

1. **Зеленая зона ($TOI \ge 60$ мин, $\ge 4$ матчей):** Узкий доверительный интервал. Полное доверие к точечной оценке при заключении контрактов и долгосрочных трансферах.
2. **Желтая зона ($20 \le TOI < 60$ мин):** Умеренный доверительный интервал. Оценка требует дифференциации по амплуа и компонентам (`rating_off` vs `rating_def`). Рекомендуется краткосрочный просмотровый контракт.
3. **Красная зона ($TOI < 20$ мин, 1 матч):** Высокая неопределенность, широкий интервал. Решение принимается исключительно в комбинации с видеоскаутингом.
